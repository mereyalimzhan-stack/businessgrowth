# BusinessGrowth

Программа лояльности и мини-CRM для малого бизнеса: кофеен, салонов, магазинов и фитнес-клубов.

Клиент сканирует QR-код на кассе, регистрируется и копит кэшбэк. Бизнес видит клиентов, проводит покупки, запускает акции и считает доходы и расходы в одном кабинете.

## Возможности

**Для бизнеса**
- Регистрация и вход с подтверждением почты по ссылке
- QR-код для кассы и готовый постер для печати
- CRM клиентов: поиск по имени, телефону и коду клиента, статусы «Новый», «Активный», «VIP»
- «Касса» на главной: ввёл код клиента — сразу открылась покупка
- Начисление кэшбэка и списание бонусов (считает сервер, накрутить нельзя)
- Акции: при запуске все клиенты программы получают уведомление
- Финансы: доходы, расходы, прибыль и маржа
- Аналитика: средний чек, доля вернувшихся клиентов, спящие клиенты, рекомендации
- Экспорт клиентов в Excel (CSV)
- Уведомления о новых клиентах

**Для клиента**
- Регистрация по QR-коду без установки приложений
- Бонусы во всех заведениях в одном кабинете
- Кнопка «Показать на кассе» с кодом и QR
- Уведомления о начислениях и акциях

**Для администратора**
- Статистика всей платформы: бизнесы, клиенты, оборот, бонусы
- Список компаний и аккаунтов, поиск, удаление аккаунтов

## Технологии

- React 18 + TypeScript
- Supabase: база данных PostgreSQL, авторизация, защита данных (Row Level Security)
- lucide-react — иконки, qrcode.react — QR-коды

## Как запустить

### 1. Supabase
1. Создайте проект на [supabase.com](https://supabase.com).
2. **SQL Editor → New query** → вставьте `supabase/schema.sql` → **Run**.
   Скрипт удаляет старые таблицы и пользователей и создаёт всё заново.
3. **Authentication → Sign In / Providers → Email** → включите **Confirm email**.
4. **Authentication → URL Configuration**:
   - **Site URL** — адрес вашего сайта;
   - **Redirect URLs** — тот же адрес с `**` в конце.

### 2. Настройки сайта
В `src/config.ts` укажите:
- `SUPABASE_URL` — Project URL из **Project Settings → API Keys**;
- `SUPABASE_ANON_KEY` — ключ `sb_publishable_...` оттуда же;
- `PUBLIC_APP_URL` — адрес опубликованного сайта (для QR-кодов). Можно оставить пустым, тогда берётся текущий адрес.

### 3. Запуск
```
npm install
npm start
```

## Роли

| Роль | Как получить |
|---|---|
| Бизнес | Регистрация с вкладкой «Бизнес» |
| Клиент | Регистрация с вкладкой «Клиент» или по QR-коду компании |
| Администратор | Email администратора задан в `schema.sql` (функция `handle_new_user`) |

## Почта

Встроенная почта Supabase отправляет письма только участникам проекта и не больше нескольких в час. Чтобы письма со ссылкой подтверждения приходили всем пользователям, подключите свой SMTP: **Authentication → Emails → SMTP Settings**.
